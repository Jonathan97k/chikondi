# Tokha Creations brand stewardship

Use this skill before changing any page copy, layout, imagery, color, typography, motion, navigation, or presentation.

## Brand and mission
Tokha Creations is a creative movement focused on art, talent, culture, and youth empowerment. Its core disciplines are music production and promotion, scriptwriting, acting, movie directing, and film production. The founder is Chikondi Simple Chagoma. The owner is Rastafarian; treat that identity respectfully and preserve the existing design language.

## Approved visual baseline
The user explicitly approved the November 5 design and repeatedly instructed that the design must not be changed. The baseline includes a dark-green cinematic hero, large TOKHA CREATIONS wordmark, existing imagery, red/gold/green Rastafari stripe, existing navigation and cards, and cream-colored content section.

These are constraints, not suggestions:
- Do not redesign or modernize the site.
- Do not change the palette, typography, logo, images, section order, spacing system, animations, navigation, footer, or component shapes unless the user explicitly asks for that specific change.
- Do not replace the visual identity with generic agency, startup, AI, or template styling.
- Do not add symbols, cultural references, or religious claims that the owner has not supplied.
- Do not use placeholder imagery or fabricated portfolio work as if it were real.

## Change protocol
1. Inspect the exact page and relevant components before editing.
2. Identify the smallest code/content change that fulfils the request.
3. Preserve existing component structure and class names wherever possible.
4. If a feature needs new UI, reuse the site's existing colors, type scale, borders, card treatment, and responsive conventions.
5. Do not modify unrelated pages.
6. Compare before/after screenshots at desktop and mobile widths when visual changes are involved.
7. If the requested change cannot be made without a material redesign, stop and ask for permission instead of making that design decision yourself.

## Editorial voice
Write confidently, creatively, and clearly. Emphasize creativity, culture, collaboration, talent development, and youth empowerment. Avoid exaggerated marketing claims, invented achievements, invented partnerships, and generic AI-sounding copy. Preserve supplied names, project titles, credits, and facts exactly.

## Required completion note
Report which content/functionality changed and explicitly state whether any visual design was changed. Never say "design unchanged" if you altered global styles or unrelated layout.
